PediBook is an application for displaying and reading content written by doctors at the Vaud University Hospital (CHUV). The application takes the form of a digital book. There is a mobile app for Android and iOS, as well as a web application.

{{<lnbreak>}}

During this project, I worked on the existing web application and carried out the following tasks:
- Audit of the existing web application: security, performance and code quality.
- Bug fixes and completion of existing features.
- Addition of an integration with the Stripe payment platform for subscription management.
