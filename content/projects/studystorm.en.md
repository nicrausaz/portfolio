**Studystorm** is a web application that helps students study more effectively. It is a platform that lets students create flashcards, quizzes and study groups.

The application makes it possible to create revision cards of the type question – single answer / multiple choice. Cards are grouped into decks. Decks can be shared with other users through a classroom system. It is also possible to start the revision mode, which lets you review the cards in random order.

This project was carried out in collaboration with four other HEIG-VD students, and was developed over the course of 3 weeks.
